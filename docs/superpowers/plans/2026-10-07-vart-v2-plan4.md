# VART v2 Plan 4: Hardening and launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a fill run 3-4x faster, make "Try with a sample company" instant and free with a guided tour of every feature, close every Plan 4 carry-over item, add the holdout eval pack, WebKit tests and the docs set, and release.

**Architecture:** Speed-up A runs a step's claimed items (or a gap check's parts) on a small thread pool, one database session, spender and cost meter per worker, so the budget and the no-transaction-across-a-model-call rule hold exactly as before. Speed-up B copies the sample company's answers from `data/dev/sample-run.json`, a snapshot written by replaying the committed eval recordings through the real endpoints: no key, no spend, and the demo shows exactly what the eval results score. A pytest regenerates it and fails on any difference. The rest is small, separate fixes (run lifecycle, interview locks, hidden content), a second synthetic company for the holdout eval, and the docs.

**Tech Stack:** Python 3.12, FastAPI, SQLAlchemy 2 + Alembic, Postgres 17 (Neon in production), `concurrent.futures` (stdlib), openpyxl, python-docx, pypdfium2, React + Vite + TypeScript + Tailwind v4, Vitest, Playwright, GitHub Actions, Vercel.

**Spec:** `docs/superpowers/specs/2026-10-03-vart-v2-design.md` (sections 5, 6.3, 8, 9, 10, 11.1 Plan 4, 12). Also binding: `docs/CONTRACTS.md` (frozen; additions only, each with a change-log line), `CLAUDE.md` (hard rules 1-11), `docs/PROGRESS.md` ("Plan 4 carry-over" and the decisions table).

## Decisions this plan makes (approved by Tarun on 2026-10-07 with the default answer to every open question: 1A, 2B, 3A, 4A, 5A, 6A, 7A; Firefox became Safari/WebKit and the guided tour was added, Decisions 16 and 17)

1. **Speed-up A: a thread pool per step, bound 8.** A questionnaire step still claims `STEP_ITEMS` (4) items, the number the frozen HTTP contract states; a gap-check step still claims outcomes whose parts add up to `STEP_PARTS` (8). Every claimed item is one job, every not-yet-stored part of a claimed outcome is one job, and the pool has `min(jobs, STEP_PARTS)` workers. Why 8:
   - it is what a step already claims, so the claim logic, the contract text and the reclaim timing do not move;
   - a step is now as slow as its slowest job (p90 about 15 s for an item, stance then draft; about 15 s for a part), so a 64-item run takes about 16 steps x 12 s = about 3.5 min instead of about 11 (3.2x), and a core gap run about 11 steps x 15 s = about 3 min instead of about 13;
   - at most 8 model calls are in flight per step and at most 9 Postgres connections (8 workers plus the request), which Neon's pooled URL multiplexes;
   - doubling `STEP_ITEMS` to 8 would roughly halve the time again but changes the frozen contract text and doubles burst pressure on providers; not needed for the 3-4x Tarun asked for.
2. **Spend and transactions under concurrency (hard rule 11).** Each worker has its own `Session` and its own `llm_budget.spender`. The spender's counters are single `INSERT ... ON CONFLICT DO UPDATE ... RETURNING` statements committed at once, so concurrent spends serialise on the counter rows and exactly the cap is allowed: the per-workspace, per-network and global caps hold exactly. Every worker spends before each call and commits before it (as the units already do). The request's session commits before the pool starts and is idle while workers call models. Lock order is the same in every worker (network row, workspace usage row, global hour, global day), so workers cannot deadlock each other.
3. **Vercel's 300 s and the step deadline.** `DEADLINE_S` (240 s) still decides whether a job, or a retry, may start. New: `HARD_S` (270 s) bounds the whole step in real time. A job still running at `HARD_S` is abandoned: its item goes back with its attempt counted (a provider that never answers ends the item as failed after `MAX_ATTEMPTS`), and the step answers. This closes carry-over N1: a step always returns before Vercel's 300 s, so the 5-minute reclaim (`STALE`) never meets a live step. Ceiling: a late job's thread may still finish its call; its cost is not added to `runs.cost_usd` (the budget counters still count it).
4. **OpenRouter rate limits and retries.** Unchanged policy: a 408, 429, 5xx, connection error or schema mismatch is retried once at once while in time; a provider failure (401, 402, 408, 429, 5xx, connection) gives the item back with its attempt kept, and a step that answered nothing is a 503 with `Retry-After: 60`. Under concurrency, a 429 burst can hit several items of one step; each keeps its attempt, and the items that succeeded are written. At most 8 calls are in flight per visitor tab, far below any provider's per-key rate.
5. **Deterministic eval replay.** The evals call `answer_item` and `check_parts`, never `step`, and a recording key is the request's content, never its order. `dev` and `gap-dev` results stay byte-identical (checked after every task).
6. **The E2E recording.** Speed-up A alone does not change it (content-addressed keys). Speed-up B does: the sample run and the core gap check are copied, and their answers come from the eval recordings, which differ from the E2E's own recorded run, so the interview flow asks other questions. The lead re-records the E2E once, in Task 9 (eval key, about $0.02). Model calls per E2E pass fall from about 210 to about 63 (the upload flow's 20 items, up to 8 interview re-checks, up to 7 Govern re-checks, and up to 8 more re-checks for the WebKit run of the sample flow, Decision 16).
7. **The network-call budget does not change.** The caps count calls per hour, and a run makes the same number of calls as before; they arrive faster. The per-network `llm` cap (400 an hour), the per-workspace step caps and the global caps (1,500 an hour, 4,000 a day) stay. A visitor can now finish about three live runs in an hour where they finished one; the caps refuse the fourth exactly as before. The default sample path now spends nothing.
8. **Speed-up B: a snapshot replayed from the eval recordings.** `scripts/sample_snapshot.py` drives the real endpoints over the sample pack with `ReplayClient` on `evals/recorded/dev.jsonl` (vsq-a and mvsp-b) and `evals/recorded/gap-dev.jsonl` (the core gap check). Verified on 2026-10-06 against `2ff1013`: every request of the three runs is in the recordings (64, 25 and 36 items; no miss, no failed answer). The snapshot names chunks as `<file name>#<line start>` and documents by file name; a copy maps them to the visitor's own copies of the sample documents.
   - **Copied when:** the workspace holds exactly the 23 sample documents with no metadata override, no upload and no statement; the questionnaire is a bundled sample with the snapshot's items (or the core gap questionnaire); and the snapshot's digest matches the deployed inputs (sample documents, sample questionnaires, stance and draft prompt versions, stance and draft models and their reasoning settings, the core CSF mapping).
   - **Otherwise live.** "Re-run live" (`?live=true`) always runs the engine; a function-scope gap check always runs live.
   - **Staying in sync.** CI: `tests/test_sample_run.py::test_the_snapshot_is_what_the_recordings_give` regenerates the snapshot and fails on any difference, so a re-recording, a prompt, model, engine or sample-data change cannot merge without a regenerated file (no key needed: `python scripts/sample_snapshot.py`). Production: `GET /api/version` gains `sample_precomputed`, and `scripts/smoke.py` fails a deploy whose models do not match the snapshot (for example a model env var changed in Vercel without a re-recording).
9. **One live run per questionnaire (Ruling 8, the stuck-run carry-over).** `POST /api/questionnaires/{id}/runs` answers 409 while a run of that questionnaire is running and was stepped in the last 10 minutes (`ABANDONED`). A running run no step has touched for 10 minutes is closed as `failed` when a new run of its questionnaire starts or a document delete is asked, so it blocks neither. A step records `runs.stepped_at` (the plan's one migration, additive). The gap check starts a new run after a `failed` one. The per-questionnaire scope follows adversary-1 M3's wording; a copy (no spend) is never refused.
10. **Confirmed answers edited (M6).** Editing a "Confirmed by you" answer stores the edit as a new dated, redacted statement and points the answer at it, counted under the `interview` cap (each pays for redaction). The earlier statement stays (a fill may cite it).
11. **Interview vs reset (deadlock carry-over).** Every write that stores or links a statement (answering a question, accepting a fill, editing a confirmed answer) takes the workspace row `FOR KEY SHARE` first, the same first lock a reset takes, so the two can no longer wait on each other.
12. **Hidden content.** Not read as evidence: docx runs marked hidden (`w:vanish`) or under 1 pt; PDF lines whose first character is under 1 pt; hidden sheets and hidden rows of an evidence workbook; hidden rows of a questionnaire (blanked, so they are never questions and never answered). Kept on purpose: PDF text in the invisible render mode, because OCR'd scans put their whole text layer there and the reader sees it as the page image. Known gaps (SECURITY.md): white or background-coloured text, text hidden by a character style, hidden columns, a tiny phrase inside a readable PDF line, text clipped outside the page.
13. **Holdout pack authoring runs in parallel.** The data builder writes the holdout company from Task 1 onward, but nothing runs the engine on it before the engine freeze tag (Task 6 Step 9), and no engine file changes after the tag (checked in Task 10). This keeps spec 7.2's guarantee (nothing could be tuned on it) and takes about 3 hours off the critical path.
14. **Preview deployments with a Neon branch are deferred.** Spec 10 says Git builds only `main` "until Plan 4 gives previews a database", but the definition of done (spec 12) does not list it; on-demand CLI previews (`vercel deploy`) cover the release's size check, and the precomputed sample would let a preview work with no model key. Building it means a `preview` phase in `ops/setup.sh` (Neon branch, migrate, purge visitor data, Preview env vars) and Tarun running it before each release. Task 11 syncs the spec line (Tarun chose this, 2B).
15. **Ledger extras for Plan 4 (not on the PROGRESS list).** Task 8 adds the custom gitleaks rule for bare OpenRouter keys. The others are written into SECURITY.md as accepted risks of a demo: PDF stream inflation can exhaust function memory (parse in a subprocess would fix it), per-network limits key on the full IPv6 address (a /64 could rotate), `/api/health` opens a database connection per hit, Vercel Git deploys do not wait for CI.

16. **Safari/WebKit instead of Firefox.** A Playwright `webkit` project (Desktop Safari) runs the smoke test and the sample flow only, in CI and locally (Task 9). It downloads WebKit once (about 80 MB, cached in CI by `npx playwright install`), adds about 2 minutes to the CI e2e job (install plus one more sample flow) and up to 8 replayed model calls a pass. At release Tarun checks Safari on the Mac and on an iPhone by hand: the sample flow, Enter on the Workspace dropdowns, and the drawer full screen under 900 px (Task 9 Step 5). The docs say plainly: Chromium-based browsers (Chrome, Brave, Comet, Edge) are covered by the Chromium tests, Safari by the WebKit tests and the manual check, and Firefox is untested. This replaces the Firefox item of the carry-over list (Workspace N2).
17. **A guided tour for onboarding (Task 3b, ui lane).** It runs on the precomputed sample run only, so it adds no model call: ten steps in app order (what VART does, documents, the questionnaire, the run grid, the evidence drawer, Questions for you, export, audit log, gap check, "not legal advice"), Next, Back, Skip and "step n of N", keys → Enter ← Esc, focus managed and steps announced. It is the default walkthrough: it starts every time the precomputed sample run opens (Tarun, 2026-10-07), with no "seen" gate and no storage; Skip or Esc closes it for that visit only, and `t` (listed in the `?` sheet) or the Tour button starts it again. Its keys work only while focus is in its card, so Enter elsewhere stays the page's (adversary-1 I4). It never starts on a visitor's own data (only `precomputed` runs), closes itself when another run opens or any run starts (Re-run live, a gap check), and never covers a live run (adversary-1 I5).

## Review Focus

1. **Several workers meeting one condition at once.** A budget refusal, a provider outage, a 429 burst or the deadline in the middle of a concurrent step. Expect: every paid call is counted once in `runs.cost_usd` and once in the budget; items that were answered are written; refused or not-started items go back with their attempt refunded; items that met the provider keep their attempt; a step that answered nothing is a 503; never a failed answer from a refusal. Pinned in Task 2: `test_a_budget_refusal_mid_step_writes_what_was_paid_and_gives_the_rest_back`, `test_an_outage_mid_step_writes_the_others_and_keeps_the_attempt_of_the_item_that_met_it`, `test_an_outage_on_every_item_is_a_503_with_no_failed_answer`, `test_spending_is_exact_under_concurrency`.
2. **A provider that hangs.** A model call that never returns inside the step. Expect: the step answers by `HARD_S`, the item goes back with its attempt counted, nothing is written for it, and Vercel never kills the function. Pinned in Task 2: `test_a_step_returns_by_its_hard_limit_and_keeps_the_slow_items_attempt`.
3. **A sample workspace that is no longer the sample, or a deploy whose models moved.** The visitor changed a document's metadata, uploaded a file, answered a question, or Vercel's model env vars differ from the snapshot's. Expect: never a copy (a copy would cite answers the engine would not give now): a live run; the smoke test fails the deploy whose models moved. Pinned in Task 3: `test_an_override_or_an_upload_falls_back_to_a_live_run`, `test_a_stale_snapshot_is_never_copied`, `test_version_says_whether_the_sample_is_precomputed`, and `tests/test_smoke.py::test_a_deploy_whose_sample_would_go_live_fails`.
4. **Two tabs, or a tab closed mid-run.** "Re-run live" in two tabs, a second run while one goes, or a run nobody steps any more. Expect: one live run per questionnaire (the second is a 409 with a sentence); a run idle for 10 minutes no longer blocks a new run or a document delete; two creates at once make exactly one run. Pinned in Task 4: `test_a_second_run_while_one_is_going_is_refused`, `test_two_new_runs_at_once_make_one`, `test_an_abandoned_run_no_longer_blocks_a_document_delete`.
5. **Content the reader cannot see.** A docx with hidden or 1-pt runs, a PDF with sub-1-pt text, an evidence workbook with hidden rows or sheets, a questionnaire with hidden rows. Expect: never cited, never asked, never answered; OCR'd scans still readable. Pinned in Task 6: the `tests/test_hidden_content.py` cases.
6. **The tour in the wrong place.** A visitor who uploads their own files, starts Re-run live, or opens a live run while the tour is open, or a browser that blocks storage. Expect: the tour never appears for a visitor's own data, never blocks or covers a live run (it closes when another run opens; the page under its card keeps working), and blocked storage only means it may show once per page load. Pinned in Task 3b: `a visitor's own run never starts the tour and has no Tour button`, `closes when the visitor opens another run, so it never sits on a live run`, `works when storage is blocked`.

```python
def _item_job(

    workspace_id: uuid.UUID,
    item: ItemInput,
    llm: LLMClient,
    models: Mapping[str, str],
    network: str | None,
    can_retry: Callable[[], bool],

def _part_job(
    engine: Engine,
    workspace_id: uuid.UUID,
    run_id: uuid.UUID,
    item_id: uuid.UUID,
    o: csf.Outcome,
    n: int,

def _keep_current_parts(
    session: Session, run_id: uuid.UUID, item_id: uuid.UUID, o: csf.Outcome, models: Mapping[str, str]
) -> list[int]:

    adversary-1 M5); return the part numbers still to run. Does not commit."""
    have = session.scalar(select(RunItem.parts).where(RunItem.run_id == run_id, RunItem.item_id == item_id)) or {}

    return [n for n in range(1, len(o.parts) + 1) if str(n) not in keep]


def _run_all(
    jobs: dict[uuid.UUID, list[Callable[[], _Done]]], in_time: Callable[[], bool], hard_at: float
) -> dict[uuid.UUID, list[_Done | None]]:
    """Every job at once, at most STEP_PARTS workers. A job that would start after the deadline is not started
    (None); a job still running at `hard_at` (time.monotonic) is late (`_Late`) and the pool is left behind
    without waiting for it. Results come back per item in the order the jobs were listed."""

    def guarded(job: Callable[[], _Done]) -> _Done | None:
        return job() if in_time() else None

    out: dict[uuid.UUID, list[_Done | None]] = {item_id: [] for item_id in jobs}
    flat = [(item_id, job) for item_id, listed in jobs.items() for job in listed]
    if not flat:
        return out
    pool = ThreadPoolExecutor(max_workers=min(len(flat), STEP_PARTS))
    futures = [(item_id, pool.submit(guarded, job)) for item_id, job in flat]
    wait([fut for _, fut in futures], timeout=max(0.0, hard_at - time.monotonic()))
    pool.shutdown(wait=False, cancel_futures=True)
    for item_id, fut in futures:
        if fut.cancelled():
            out[item_id].append(None)  # never started: as if the deadline kept it
        elif fut.done():
            out[item_id].append(fut.result())
        else:
            out[item_id].append(_Done(None, 0.0, _Late()))
    return out


def _worst(errors: list[Exception]) -> Exception:

    the first of the rest."""

            if isinstance(e, kind):

    for e in errors:
```

```python
def step(
    session: Session,
    workspace_id: uuid.UUID,
    run_id: uuid.UUID,
    llm: LLMClient,
    models: Mapping[str, str],
    *,
    clock: Callable[[], float] = time.monotonic,
    now: datetime | None = None,
    network: str | None = None,
) -> list[uuid.UUID]:
    """Answer the claimed items at once (Plan 4 Task 2): up to STEP_ITEMS questionnaire items, or the parts of
    gap-check outcomes up to STEP_PARTS, each job on a worker thread with its own session, spender and cost meter,
    spending before every model call and holding no transaction across one. A job starts, or retries, only
    before DEADLINE_S (`clock`); the step answers by HARD_S in real time. Then, on this thread in questionnaire
    order: write every answer that came back (one row per item; a duplicate write does nothing), count every paid
    call, give back the items that met a refusal, a missing recording or the deadline (attempt refunded) or that
    met an outage or were late (attempt kept). Raises, after the writes: ReplayMiss, then a `llm_budget.Refused`
    naming the cap, then an unexpected error (its item stays claimed), then ModelsUnavailable when nothing was
    answered. Returns the item ids answered. `network` is `errors.network(request)`: each spender counts each
    call for it."""
    run = _run(session, workspace_id, run_id)
    if run.status != "running":
        return []
    by_parts = (
        session.scalar(select(Questionnaire.source).where(Questionnaire.id == run.questionnaire_id)) == "csf"
    )
    hard_at = time.monotonic() + HARD_S  # real time: it bounds real waiting, whatever `clock` says
    deadline = clock() + DEADLINE_S
    claimed = _claim(session, run_id, now or datetime.now(UTC), by_parts=by_parts)
    engine = session.get_bind()
    assert isinstance(engine, Engine)

    def in_time() -> bool:
        return clock() <= deadline

    jobs: dict[uuid.UUID, list[Callable[[], _Done]]] = {}
    ready: dict[uuid.UUID, dict[str, Any]] = {}  # answered with no model call
    outcomes: dict[uuid.UUID, csf.Outcome] = {}
    for n, (item_id, attempts) in enumerate(claimed):
        try:
            if attempts >= MAX_ATTEMPTS:
                ready[item_id] = FAILED
                continue
            row = session.get_one(Item, item_id)
            # an id a data refresh withdrew is answered as the question it was (adversary-1 N1)
            o = csf.outcome_or_none(row.csf_id) if row.csf_id is not None else None
            if o is None:
                item = ItemInput(str(row.id), row.question, row.topic)
                jobs[item_id] = [partial(_item_job, engine, workspace_id, item, llm, models, network, in_time)]
            elif o.tier != "checked":
                ready[item_id] = dict(ASK)
            else:
                outcomes[item_id] = o
                jobs[item_id] = [
                    partial(_part_job, engine, workspace_id, run_id, item_id, o, k, llm, models, network, in_time)
                    for k in _keep_current_parts(session, run_id, item_id, o, models)
                ]
        except Exception:
            _keep_cost(session, run_id, 0.0, claimed[n + 1 :])  # this item stays claimed; the rest go back
            raise
    session.commit()  # the request's session holds no transaction while the workers call models
    results = _run_all(jobs, in_time, hard_at)

    answered: list[uuid.UUID] = []
    give_back: list[uuid.UUID] = []
    keep_attempt: list[uuid.UUID] = []
    replay: ReplayMiss | None = None
    refused: BudgetExhausted | None = None
    crashed: Exception | None = None
    for n, (item_id, _) in enumerate(claimed):
        if item_id in ready:
            _write(session, workspace_id, run_id, item_id, ready[item_id], 0.0)
            answered.append(item_id)
            continue
        done = results.get(item_id, [])
        cost = sum(d.cost for d in done if d is not None)
        errors = [d.error for d in done if d is not None and d.error is not None]
        if not errors and None not in done:
            try:
                values = (
                    outcome_values(outcomes[item_id], _stored(session, run_id, item_id))
                    if item_id in outcomes
                    else done[0].values  # type: ignore[union-attr]
                )
                _safe_write(session, workspace_id, run_id, item_id, values or FAILED, cost)
            except Exception:
                rest = sum(d.cost for i, _ in claimed[n + 1 :] for d in results.get(i, []) if d is not None)
                _keep_cost(session, run_id, cost + rest, claimed[n + 1 :])
                raise
            answered.append(item_id)
            continue
        _add_cost(session, run_id, cost)
        session.commit()
        if not errors:  # the deadline kept a job from starting: not tried, so no attempt spent
            give_back.append(item_id)
            continue
        err = _worst(errors)
        if isinstance(err, ReplayMiss):
            replay = replay or err
            give_back.append(item_id)
        elif isinstance(err, BudgetExhausted):
            refused = refused or err
            give_back.append(item_id)
        elif isinstance(err, _Late) or (isinstance(err, LLMError) and _provider_down(err)):
            keep_attempt.append(item_id)  # an item the provider always fails still ends FAILED (adversary-3 N1)
        elif isinstance(err, LLMError) and _retryable(err) and not in_time():
            give_back.append(item_id)  # the deadline cut the retry: not tried twice, so not failed
        elif isinstance(err, (LLMError, SQLAlchemyError)):
            if isinstance(err, SQLAlchemyError):  # the type only: its parameters carry the question's words
                log.error("run %s item %s: %s; answered as failed", run_id, item_id, type(err).__name__)
            _write(session, workspace_id, run_id, item_id, FAILED, 0.0)  # its cost is already added
            answered.append(item_id)
        else:
            crashed = crashed or err  # stays claimed with its attempt counted: a crash loop ends at MAX_ATTEMPTS
    _release(session, run_id, give_back)
    _release(session, run_id, keep_attempt, refund=False)
    if replay is not None:
        raise replay
    if refused is not None:
        kind = str(refused.args[0]) if refused.args else "stance"
        scope = (
            refused.scope if isinstance(refused, Refused) else refusal_scope(session, workspace_id, kind, network)
        )
        raise Refused(kind, scope) from None
    if crashed is not None:
        raise crashed
    if keep_attempt and not answered:
        raise ModelsUnavailable()  # when something was answered, the next step meets the outage itself
    _finish_if_done(session, run)
    return answered
```

```python
@cache
def _digest(models_key: tuple[tuple[str, str], ...]) -> str:
    h = hashlib.sha256()
    for name in SAMPLE_ORDER:
        h.update(name.encode() + b"\0" + (DOCS / name).read_bytes())
    for name in QUESTIONNAIRES:
        h.update(name.encode() + b"\0" + (QDIR / name).read_bytes())
    models = dict(models_key)
    meta = {
        "prompts": [STANCE_PROMPT, DRAFT_PROMPT],
        "models": models,
        "reasoning": {step: reasoning_for(step, models[step]) for step in STEPS},
        "csf": csf.current_mapping("core"),
    }
    h.update(json.dumps(meta, sort_keys=True).encode())
    return h.hexdigest()[:16]


def digest(models: Mapping[str, str]) -> str:
    """What the snapshot's answers depend on and the CI regeneration test cannot see in production: the sample
    documents and questionnaires, the stance and draft prompts, models and reasoning, the core CSF mapping."""
    return _digest(tuple((step, models[step]) for step in STEPS))


@cache
def snapshot() -> dict[str, Any] | None:
    if not SNAPSHOT.exists():
        return None
    loaded: dict[str, Any] = json.loads(SNAPSHOT.read_text(encoding="utf-8"))
    return loaded


def _current(models: Mapping[str, str]) -> dict[str, Any] | None:
    snap = snapshot() if ENABLED else None
    return snap if snap is not None and snap["digest"] == digest(models) else None


def ready(models: Mapping[str, str]) -> bool:
    """The deployed inputs match the snapshot, so the sample path is copied (GET /api/version, the smoke test)."""
    return _current(models) is not None


def swap(values: Any, chunk: Callable[[str], str], doc: Callable[[str], str]) -> Any:
    """Every `chunk_id`, `document_id` and `chunk_ids` in a nested answer value, rewritten by `chunk` and `doc`.
    The snapshot names a chunk "<file name>#<line start>" and a document by its file name; a workspace holds its
    own ids. A name `chunk` or `doc` does not know raises KeyError."""
    if isinstance(values, list):
        return [swap(v, chunk, doc) for v in values]
    if not isinstance(values, dict):
        return values
    out = {k: swap(v, chunk, doc) for k, v in values.items()}
    if isinstance(out.get("chunk_id"), str):
        out["chunk_id"] = chunk(out["chunk_id"])
    if isinstance(out.get("document_id"), str):
        out["document_id"] = doc(out["document_id"])
    if isinstance(out.get("chunk_ids"), list):
        out["chunk_ids"] = [chunk(c) for c in out["chunk_ids"]]
    return out


def _sample_pack_only(session: Session, workspace_id: uuid.UUID) -> bool:
    """The workspace holds the sample pack and nothing else, with no metadata changed: only then do the
    snapshot's answers describe it (an upload, an answer to a question or an override changes what the engine
    would say)."""
    docs = session.execute(
        select(Document.filename, Document.source, Document.metadata_source).where(
            Document.workspace_id == workspace_id
        )
    ).all()
    return sorted(d.filename for d in docs) == sorted(SAMPLE_ORDER) and all(
        d.source == "sample" and d.metadata_source == "rule" for d in docs
    )


def _copy(
    session: Session,
    workspace_id: uuid.UUID,
    q: Questionnaire,
    pairs: list[tuple[Item, dict[str, Any]]],
    snap: dict[str, Any],
    models: Mapping[str, str],
) -> Run | None:
    rows = session.execute(
        select(Chunk.id, Chunk.line_start, Document.id, Document.filename)
        .join(Document, Document.id == Chunk.document_id)
        .where(Chunk.workspace_id == workspace_id)
    ).all()
    chunks = {f"{name}#{line}": str(cid) for cid, line, _, name in rows}
    docs = {name: str(did) for _, _, did, name in rows}
    try:
        local = [
            (
                item,
                swap(e["values"], chunks.__getitem__, docs.__getitem__),
                swap(e.get("parts", {}), chunks.__getitem__, docs.__getitem__),
            )
            for item, e in pairs
        ]
    except KeyError:  # a chunk the snapshot cites is not in this workspace: never copy a dangling citation
        return None
    run = Run(
        workspace_id=workspace_id,
        questionnaire_id=q.id,
        status="done",
        finished_at=datetime.now(UTC),
        prompt_versions=snap["prompt_versions"],
        models={**dict(models), "snapshot": snap["digest"]},
    )
    session.add(run)
    session.flush()
    for item, values, parts in local:
        session.add(RunItem(run_id=run.id, item_id=item.id, state="done", parts=parts))
        session.add(Answer(workspace_id=workspace_id, run_id=run.id, item_id=item.id, **values))
    audit_log.record(
        session, workspace_id, "run.create", ref=str(run.id), detail={"items": len(local), "precomputed": True}
    )
    session.commit()
    return run


def copy_questionnaire_run(
    session: Session, workspace_id: uuid.UUID, questionnaire_id: uuid.UUID, models: Mapping[str, str]
) -> Run | None:
    """A bundled sample questionnaire's run, copied; None when anything differs from the snapshot's world."""
    snap = _current(models)
    q = session.scalar(
        select(Questionnaire).where(
            Questionnaire.id == questionnaire_id, Questionnaire.workspace_id == workspace_id
        )
    )
    if snap is None or q is None or q.source != "sample" or q.filename not in snap["questionnaires"]:
        return None
    if not _sample_pack_only(session, workspace_id):
        return None
    items = list(session.scalars(select(Item).where(Item.questionnaire_id == q.id).order_by(Item.position)))
    want = snap["questionnaires"][q.filename]["items"]
    if [(i.position, i.question, i.topic) for i in items] != [
        (e["position"], e["question"], e["topic"]) for e in want
    ]:
        return None
    return _copy(session, workspace_id, q, list(zip(items, want, strict=True)), snap, models)


def copy_gap_run(
    session: Session, workspace_id: uuid.UUID, q: Questionnaire, models: Mapping[str, str]
) -> Run | None:
    """The core gap check's run, copied; None for another scope or anything that differs."""
    snap = _current(models)
    if snap is None or (q.mapping or {}).get("scope") != "core" or not _sample_pack_only(session, workspace_id):
        return None
    items = {i.csf_id: i for i in session.scalars(select(Item).where(Item.questionnaire_id == q.id))}
    want = snap["gap"]["items"]
    if sorted(str(k) for k in items) != sorted(e["csf_id"] for e in want):
        return None
    return _copy(session, workspace_id, q, [(items[e["csf_id"]], e) for e in want], snap, models)
```

```python
def _finish(client: TestClient, run_id: str) -> None:
    while client.get(f"/api/runs/{run_id}").json()["status"] == "running":
        res = client.post(f"/api/runs/{run_id}/step")
        if res.status_code != 200:
            raise SystemExit(f"step failed: {res.status_code} {res.text[:300]}")


def _names(s: Session, workspace_id: uuid.UUID) -> tuple[dict[str, str], dict[str, str]]:
    rows = s.execute(
        select(Chunk.id, Chunk.line_start, Document.id, Document.filename)
        .join(Document, Document.id == Chunk.document_id)
        .where(Chunk.workspace_id == workspace_id)
    ).all()
    chunks = {str(cid): f"{name}#{line}" for cid, line, _, name in rows}
    if len(set(chunks.values())) != len(chunks):
        raise SystemExit("two chunks of one document start on the same line: the snapshot cannot name them")
    return chunks, {str(did): name for _, _, did, name in rows}


def _entries(s: Session, run_id: uuid.UUID, chunks: dict[str, str], docs: dict[str, str]) -> list[dict[str, Any]]:
    rows = s.execute(
        select(Item, Answer, RunItem.parts)
        .join(Answer, (Answer.item_id == Item.id) & (Answer.run_id == run_id))
        .join(RunItem, (RunItem.item_id == Item.id) & (RunItem.run_id == run_id))
        .order_by(Item.position)
    ).tuples()
    out: list[dict[str, Any]] = []
    for item, a, parts in rows:
        if a.text == FAILED_TEXT or a.statement_id is not None:
            raise SystemExit(f"{item.code}: not a clean engine answer; check the recordings")
        values = {k: getattr(a, k) for k in sample_run.ANSWER_FIELDS}
        entry: dict[str, Any] = {
            "position": item.position,
            "question": item.question,
            "topic": item.topic,
            "csf_id": item.csf_id,
            "values": sample_run.swap(values, chunks.__getitem__, docs.__getitem__),
        }
        if parts:
            entry["parts"] = sample_run.swap(parts, chunks.__getitem__, docs.__getitem__)
        out.append(entry)
    return out


def build(client: TestClient, engine: Engine) -> dict[str, Any]:
    """The snapshot, from a fresh workspace on `client`'s cookie. Resets that workspace when done."""
    models = get_settings().models()
    sample_run.ENABLED = False  # never copy the old snapshot while making the new one
    try:
        assert client.get("/api/workspace").status_code == 200
        assert client.post("/api/documents/sample").status_code == 201
        app.dependency_overrides[get_llm] = lambda: ReplayClient(RECORDED / "dev.jsonl")
        runs: dict[str, str] = {}
        for name, filename in SAMPLES.items():
            q = client.post(f"/api/questionnaires/sample/{name}").json()
            run = client.post(f"/api/questionnaires/{q['id']}/runs", params={"live": "true"}).json()
            _finish(client, run["id"])
            runs[filename] = run["id"]
        app.dependency_overrides[get_llm] = lambda: ReplayClient(RECORDED / "gap-dev.jsonl")
        gap = client.post("/api/gap/core/run").json()
        _finish(client, gap["id"])
    finally:
        app.dependency_overrides.pop(get_llm, None)
        sample_run.ENABLED = True
    with Session(engine) as s:
        g = s.get_one(Run, uuid.UUID(gap["id"]))
        chunks, docs = _names(s, g.workspace_id)
        snap = {
            "digest": sample_run.digest(models),
            "models": {step: models[step] for step in sample_run.STEPS},
            "prompt_versions": g.prompt_versions,
            "questionnaires": {f: {"items": _entries(s, uuid.UUID(r), chunks, docs)} for f, r in runs.items()},
            "gap": {"scope": "core", "items": _entries(s, g.id, chunks, docs)},
        }
    text = json.dumps(snap, sort_keys=True, ensure_ascii=False)
    if found := _UUID.search(text):
        raise SystemExit(f"an id the snapshot does not map: {found.group()}")
    client.post("/api/workspace/reset")
    loaded: dict[str, Any] = json.loads(text)
    return loaded


def main() -> int:
    if "test" not in (make_url(database_url()).database or ""):
        print("refusing to run: DATABASE_URL must point at a test database", file=sys.stderr)
        return 2
    snap = build(TestClient(app), get_engine())

    )
    n = sum(len(q["items"]) for q in snap["questionnaires"].values())
    print(f"wrote data/dev/sample-run.json: {n} questionnaire items, {len(snap['gap']['items'])} gap outcomes")
    return 0

    raise SystemExit(main())
```

**What it is.** After "Try with a sample company" the visitor gets a step-by-step tour of every feature, on the precomputed sample run (Task 3). Ten steps in app order, each with a short title, one or two plain sentences for someone new to compliance, and the real UI element outlined. Next, Back, Skip and "step n of N"; → or Enter for next, ← for back, Esc to skip. It starts by itself the first time a precomputed sample run opens, and `t` (or the "Tour" button on that run, listed in the `?` sheet) starts it again. "Seen" is kept in `localStorage` inside try/catch, plus an in-memory flag, so a blocked storage only means the tour may show once per page load. It never starts on a visitor's own run (only `RunOut.precomputed` runs start it, and only those show the button), and it closes itself the moment the visitor opens another run (for example Re-run live), so it never sits on a live run. The card is not modal: the page under it keeps working. Design direction C: monochrome tokens only, a full-width card at the bottom under 900 px (above the status line), a 22rem card at the bottom right from 900 px, no new dependency. It moves between views with the existing query-string routes (`go`).

```ts
type State = { open: boolean; step: number; ctx: TourContext | null };
let state: State = { open: false, step: 0, ctx: null };
let seenThisPage = false; // storage can be blocked: then the tour still shows only once per page load
const listeners = new Set<() => void>();

function set(next: State): void {
  state = next;
  for (const l of listeners) l();
}

function subscribe(cb: () => void): () => void {
  listeners.add(cb);
  return () => listeners.delete(cb);
}

export function useTour(): State {
  return useSyncExternalStore(subscribe, () => state);
}

function seen(): boolean {
  if (seenThisPage) return true;
  try {
    return window.localStorage.getItem(SEEN_KEY) === "1";
  } catch {
    return false;
  }
}

function markSeen(): void {
  seenThisPage = true;
  try {
    window.localStorage.setItem(SEEN_KEY, "1");
  } catch {
    // storage blocked (private mode, a policy): the in-memory flag covers this page load
  }
}

export function startTour(ctx: TourContext): void {
  markSeen();
  set({ open: true, step: 0, ctx });
}

/** The first time a precomputed sample run opens. */
export function maybeStartTour(ctx: TourContext): void {
  if (!state.open && !seen()) startTour(ctx);
}

export function moveTour(by: number): void {
  if (!state.open) return;
  const step = state.step + by;
  if (step < 0) return;
  if (step >= STEPS.length) return stopTour();
  set({ ...state, step });
}

export function stopTour(): void {
  if (state.open) set({ ...state, open: false, step: 0 });
}

export function resetTourForTests(): void {
  seenThisPage = false;
  set({ open: false, step: 0, ctx: null });
}
```

```tsx
import { useEffect, useRef } from "react";
import { inTextField } from "../lib/keys";
import { go, href, useRoute } from "../lib/route";
import { STEPS, moveTour, stopTour, useTour } from "../lib/tour";
import { Button } from "./ui";

/** The guided tour's card (Plan 4 Task 3b). Not modal: the page under it keeps working. While open it takes →,
 * Enter, ← and Esc (outside text fields) before the views' keys, outlines the step's `data-tour` element, moves
 * focus to Next on every step and gives focus back when it closes. It closes itself when another run opens. */
export default function Tour() {
  const { open, step, ctx } = useTour();
  const route = useRoute();
  const box = useRef<HTMLDivElement>(null);
  const s = STEPS[step];

  useEffect(() => {
    if (!open || !ctx) return;
    const r = s.route(ctx);
    if (r && href(r) !== window.location.search) go(r);
  }, [open, step, ctx, s]);

  useEffect(() => {
    if (open && ctx && route.run && route.run !== ctx.runId) stopTour(); // never on a live or another run
  }, [open, ctx, route.run]);

  useEffect(() => {
    if (!open) return;
    let el: Element | null = null;
    let frame = 0;
    let tries = 0;
    const find = () => {
      el = document.querySelector(`[data-tour="${s.target}"]`);
      if (el) {
        el.setAttribute("data-tour-on", "");
        el.scrollIntoView?.({ block: "nearest" });
      } else if (tries++ < 120) {
        frame = requestAnimationFrame(find); // the view may still be loading
      }
    };
    find();
    return () => {
      cancelAnimationFrame(frame);
      el?.removeAttribute("data-tour-on");
    };
  }, [open, s, route.view, route.item]);

  useEffect(() => {
    if (open) box.current?.querySelector<HTMLElement>('[aria-keyshortcuts="ArrowRight"]')?.focus();
  }, [open, step]);

  useEffect(() => {
    if (!open) return;
    const opener = document.activeElement;
    const onKey = (e: KeyboardEvent) => {
      if (e.ctrlKey || e.metaKey || e.altKey) return;
      if (e.key === "Escape") stopTour();
      else if (inTextField(e.target)) return;
      else if (e.key === "ArrowRight" || e.key === "Enter") moveTour(1);
      else if (e.key === "ArrowLeft") moveTour(-1);
      else return;
      e.preventDefault();
      e.stopImmediatePropagation();
    };
    window.addEventListener("keydown", onKey, true);
    return () => {
      window.removeEventListener("keydown", onKey, true);
      if (opener instanceof HTMLElement && opener.isConnected) opener.focus();
    };
  }, [open]);

  if (!open || !ctx) return null;
  const last = step === STEPS.length - 1;
  return (
    <div
      ref={box}
      role="dialog"
      aria-label="guided tour"
      aria-describedby="tour-body"
      className="fixed inset-x-0 bottom-7 z-30 border-t border-ink bg-paper p-4 text-sm min-[900px]:inset-x-auto min-[900px]:right-4 min-[900px]:bottom-9 min-[900px]:w-[22rem] min-[900px]:border"
    >
      <p className="text-xs text-ink-3">step {step + 1} of {STEPS.length}</p>
      <h2 className="mt-1 text-base font-medium">{s.title}</h2>
      <p id="tour-body" className="mt-1 text-ink-2">{s.body}</p>
      <p role="status" className="sr-only">{`Step ${step + 1} of ${STEPS.length}: ${s.title}. ${s.body}`}</p>
      <div className="mt-3 flex flex-wrap gap-2">
        <Button k="←" shortcut="ArrowLeft" label="Back" onClick={() => moveTour(-1)} disabled={step === 0} />
        <Button k="→" shortcut="ArrowRight" label={last ? "Done" : "Next"} primary onClick={() => moveTour(1)} />
        <Button k="esc" shortcut="Escape" label="Skip" onClick={stopTour} />
      </div>
    </div>
  );
}
```

```python
# val 0/false/off) or under 1 pt (w:sz is in half-points). ponytail: run properties only; text hidden by a character

    './/w:r[w:rPr/w:vanish[not(@w:val) or not(@w:val="0" or @w:val="false" or @w:val="off")]'
    " or w:rPr/w:sz[number(@w:val) < 2]]"

_SHEET_NS = "{http://schemas.openxmlformats.org/spreadsheetml/2006/main}"


def hidden_rows(ws: Any) -> set[int]:
    """Row numbers a read-only worksheet marks hidden. openpyxl's read-only reader drops row attributes, so the
    sheet's XML is streamed once more for them, keeping memory flat (each finished row is cleared from its
    parent). ponytail: `_get_source` is openpyxl's private reader (pinned 3.1.5 in requirements-dev.txt); hidden
    columns are not handled (docs/SECURITY.md)."""
    hidden: set[int] = set()
    n = 0
    data = None
    with ws._get_source() as src:
        for event, el in iterparse(src, events=("start", "end")):
            if event == "start" and el.tag == _SHEET_NS + "sheetData":
                data = el
            elif event == "end" and el.tag == _SHEET_NS + "row":
                n = int(float(el.get("r") or n + 1))
                if el.get("hidden") in ("1", "true"):
                    hidden.add(n)
                if data is not None:
                    data.clear()
    return hidden
```

```markdown
Passage text is data, and every system prompt says so. Passages that match the injection patterns are removed
before any model call and shown as dropped [app/patterns.py, app/retrieve.py]. Labels come from code, not from the
model; every quote is re-read from the stored line; the drafted answer may only name cited documents and numbers in
cited quotes. The eval gates CI on zero injections followed, on the dev and holdout packs.

## Limits and cost guards
- Per network, an hour: 20 new workspaces, 60 uploads, 20 runs, 400 model calls, 60 interview answers, 60 exports
  [app/services/ip_limits.py LIMITS].
- Per workspace, an hour, per step: stance 150, draft 120, classify 40, recheck 60 model calls; for everyone: 1,500
  model calls an hour and 4,000 a day, counted where a workspace reset cannot refund them
  [app/services/llm_budget.py].
- The OpenRouter key has its own credit limit; the daily canary reports low credit on /api/health.
- Uploads: PDF, DOCX, XLSX, CSV, MD and TXT, checked by content; at most 4 MB per file, 20 uploaded documents and
  20,000 lines per workspace, 1,000,000 characters per document, 150 questions and 1 MB per questionnaire, 5
  questionnaires; Office files over 50 MB unpacked or 5,000 parts are refused; Word files with tracked changes and
  PDFs with no text layer are refused [app/ingest/parse.py, app/ingest/pdf.py, app/questionnaires.py,
  app/api/schemas.py]. A storage breaker refuses new work when the database is near its size limit.
- The sample company's run is precomputed, so the default path spends nothing.

## Isolation
A signed, HttpOnly, SameSite=Lax cookie (Secure on Vercel) names the workspace; every query is scoped to it, and
another workspace's ids answer 404. Cross-site writes are refused with 403 before any route runs. Exported cells are
written as inert text, so a formula in an answer never runs in the buyer's spreadsheet [app/export.py].

## Secrets
No secret is in the repository or its history: gitleaks scans every commit in CI, with an added rule for bare
OpenRouter keys. Production secrets live only in Vercel's environment variables; the eval key lives in a mode-600
file outside the repository with a $5 credit limit.

## Accepted risks of a demo
- A small PDF whose streams inflate past the function's memory can crash its instance; on Fluid compute that ends
  every request in flight there. Parsing in a subprocess with a memory limit would fix it.
- Per-network limits key on the full client address; an IPv6 visitor can rotate within a /64.
- /api/health opens a database connection on every request.
- Vercel deploys main without waiting for CI; releases go through a pull request with green CI first.

## What real use would need
Single sign-on and roles; customer-managed encryption keys; a data processing agreement and zero-retention routing
with every model provider; malware scanning of uploads; OCR for scanned PDFs; a review step for redaction; longer,
customer-controlled retention and audit export; per-tenant isolation; and an independent security assessment.
```
