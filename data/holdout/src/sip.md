# Security Roadmap

Marrowgate Labs Ltd - Version 1.0 - Effective 2026-07-15

## Resilience

Failover of the payroll calculation service to the secondary region has not been exercised; a first test is planned for 2027.

## Vulnerability Programs

A public bug bounty program is being evaluated for 2028.

## Tooling

Marrowgate plans to replace its ticket-based onboarding checklist with an automated workflow.
